## Publication controls and limitations

GitHub repository is public with `main` as its default branch. No history was overwritten or force-pushed. Vercel has no Git repository connection, and `vercel.json` sets `git.deploymentEnabled` to `false` for every branch. Deployment is manual.

`.gitignore` and `.vercelignore` exclude secrets, local authentication files, generated builds, caches, review artifacts, and local agent settings. Vercel created an ignored `.env.local` during linking; it was not uploaded or committed. Asset licenses remain in `public/licenses/` and `docs/ATTRIBUTION.md`.

Preview and immutable deployment URLs retain Vercel authentication; the production domain is publicly accessible. No dependencies were upgraded, no Remotion was installed, and no artwork or visual refinements were made.

Verification used desktop Chromium with a responsive mobile viewport. Physical mobile GPUs, actual touch gestures, Safari, Firefox, audio output quality, and sustained performance were not tested in this release. Existing development observations remain in `docs/VERIFICATION.md`. No performance guarantee is implied. No log drains or additional external monitoring were configured.
